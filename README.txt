2. OTHER WORKS
Place your other photos in:
images/works/

The draft currently expects:
01.jpg through 06.jpg

To add more, open works.html and duplicate one of the <figure class="photo-card work-card"> blocks.
Then change the image filename, title and tags.

3. TAGS
Tags are directly in index.html and works.html.

Example:
<span class="tags">#street #singapore #night</span>

For the fullscreen viewer, also change:
data-tags="#street #singapore #night"

4. ABOUT PAGE
Open about.html and replace:
- the placeholder biography
- Instagram href="#"
- LinkedIn href="#"

5. VIEWING THE SITE
Double-click index.html.

The site uses local image files. The Google font will load when you have an internet connection;
if you are offline, it falls back to Georgia/Arial.

6. IMAGE SIZING
The gallery intentionally uses object-fit: cover so all thumbnails line up.
Click a photograph to see the full uncropped image.

Featured:
- Row 1: 3 photographs
- Row 2: 4 photographs
- Horizontally scrollable if the viewport is too small

Works:
- 2 photographs per row on desktop
- 1 photograph per row on smaller screens
